# Planos cobrados pelo Stripe, com Limites contados no nosso banco

A Organização assina um Plano pago pelo Stripe Checkout e gerencia a Assinatura no portal do Stripe. O Stripe nos avisa por webhook, e guardamos uma linha de Assinatura por Organização com o estado que ele mandou. Os Limites de cada Plano ficam no código, e o uso do mês é contado nas nossas tabelas de Trabalho e Mensagem, as mesmas da página de Uso. Os Códigos de uso também são nossos: somam Créditos ao Limite do mês e não passam pelo Stripe. Os cupons de desconto do Stripe continuam valendo no Checkout.

Descartamos a cobrança por uso medido no Stripe (metered billing) porque cada Trabalho viraria uma chamada externa, e uma falha do Stripe pararia os Bots. Também descartamos guardar os Limites no Stripe (metadados do produto), porque o servidor teria de consultar o Stripe antes de cada pedido. O custo da escolha é manter os Planos em dois lugares: o preço no Stripe (`STRIPE_PRICE_PRO`) e os Limites no código. Falamos com o Stripe pela API REST via `fetch`, sem o SDK, para os testes poderem simulá-lo com MSW como as outras APIs externas. A assinatura do webhook é conferida com `STRIPE_WEBHOOK_SECRET`, e cada evento é processado uma vez só.
