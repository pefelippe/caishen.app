# Finanças pertencem ao Titular, não ao Usuário

Organização e Usuário modelam acesso; as finanças (Obrigações, Renda, Avaliação) pertencem a um **Titular**, que pode ou não estar ligado a um Usuário. Um rating é sempre de uma pessoa (CPF), e uma Organização pode acompanhar várias pessoas — uma família, ou um consultor com clientes que nunca fazem login. Colapsar Titular em Usuário obrigaria todo avaliado a ter conta.
